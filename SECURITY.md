# Security policy

## Scope

This repository holds experiments with GitHub procedures: workflows, repository rules, issue and pull request flows, releases. It ships no software for use.

## What to report privately

- A secret, a credential or personal data committed to this repository by mistake.
- A weakness of the workflows under `.github/` that could let someone change what the repository runs or publishes.

## How to report

Write to [info@mtorun0x7cd.com](mailto:info@mtorun0x7cd.com), naming the file, the problem and how to see it. Do not open a public issue for it.

## What to expect

Reports are read. A reply or a fix is not guaranteed.
